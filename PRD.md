# 🎯 KeepOnMe - Product Requirements Document (PRD)

## 1. 프로젝트 개요 (Overview)

- **서비스명**: KeepOnMe
- **한 줄 설명**: 1:1 메이트 기반의 선한 감시(Friendly Surveillance)와 목표 달성 점검 웹 서비스
- **타겟 사용자**: 친구와 함께 서로를 감시/격려하며 작심삼일을 극복하고 습관을 형성하려는 사용자

---

## 2. 핵심 기능 요구사항 (Core Features)

### 2.1 목표 관리 (Goal Management)

- **주간 목표 (Weekly Goals)**: 매주 시작 시 장기/핵심 목표 설정 및 진행률 체크
- **일일 투두 (Daily Todos)**: 매일 실천할 개별 할 일 CRUD 및 완료 토글
- **연속 달성(Streak) 및 달성률(%)**: 당일 및 주간 목표 달성 비율 실시간 계산

### 2.2 메이트 감시 및 인터랙션 (Peer Accountability)

- **1:1 메이트 연결**: 초대 코드(Invite Code)를 통한 간편 매칭
- **메이트 감시소 (Mate View)**: 친구의 실시간 투두 현황, 달성률, 인증 상태 확인
- **찌르기 (Poke)**: 미완료 항목에 대해 즉시 자극/경고 푸시 알림 전송
- **인증 및 상호 검수 (Verification)**: 완료 체크 시 사진/메모 제출 → 메이트의 승인(Approved) 또는 반려(Rejected) 처리

---

## 3. UI/UX 화면 구성 (Single View with Tabs)

화면 분할(Split) 없이, PC와 모바일 모두 **단일 뷰 + 상단 탭 전환** 방식으로 몰입도 제공.

```text
+-----------------------------------------------------------------------------------+
|  🎯 KeepOnMe                 [ 2026.08.17 (월) ]           [🔔 찌르기 알림 2] [설정] |
+-----------------------------------------------------------------------------------+
|                                                                                   |
|    +------------------------------------+------------------------------------+    |
|    |      👉 [🧑 내 대시보드]           |        [🕵️ 메이트 감시소 (1)]      |    |
|    +------------------------------------+------------------------------------+    |
|                                                                                   |
|  [프로필 / 달성률 요약]                                                           |
|  - 연속 달성 일수 (Streak 🔥) / 오늘의 달성률 (%) 프로그레스 바                     |
|                                                                                   |
|  [📌 이번 주 핵심 목표 (Weekly Goals)]                                             |
|  - 주간 목표 목록 및 추가 버튼                                                     |
|                                                                                   |
|  [✅ 오늘의 할 일 (Daily Todos)]                                                  |
|  - 탭 A (내 대시보드): 투두 체크박스, 할 일 추가, [📷 인증샷 업로드] 버튼         |
|  - 탭 B (메이트 감시소): 메이트 투두 확인, [👉 찌르기] 버튼, [🔍 인증 승인/반려]   |
|                                                                                   |
|  [💬 오늘의 다짐 / 🚨 종합 찌르기 한마디]                                         |
+-----------------------------------------------------------------------------------+
```
